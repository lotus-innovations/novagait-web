# Security

This is a demonstration project by Lotus Innovations. It contains no real
user data, no credentials, and no backend services; all content is synthetic.

To report a security issue in this repository or any Lotus Innovations
property, contact us via https://lotusinnovations.io (contact form) and
include the repository name and a reproduction. We respond to reports on a
best-effort basis.

Please do not open public issues for suspected vulnerabilities.
