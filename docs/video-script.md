# Walkthrough video script (60 to 90 seconds)

Narration for the portfolio/gig video. Raw screen captures live outside the
repo; this script is the single source for the voiceover. Target: one take,
about 85 seconds at a calm pace.

| # | Screen capture | Narration |
|---|----------------|-----------|
| 1 | demo.lotusinnovations.io home, light theme, hero gait-line draws | "This is Novagait, a fictional clinic we built twice to show what accessibility remediation actually looks like." |
| 2 | Exhibit page, side-by-side frames | "The before version carries twelve realistic barriers, the kind real audits find every week. The after version fixes every one." |
| 3 | Before contact form: submit empty, borders turn red silently | "Here is the before form. Submit it empty and the only feedback is a red border. A screen reader hears nothing." |
| 4 | After contact form: submit empty, error summary appears and is focused; then filled and submitted, confirmation with reference | "The remediated form announces every problem, links each one to its field, and confirms success with focus moved to the answer." |
| 5 | Exhibit barrier card V3 (contrast) with before/after code | "Every barrier is annotated: who it blocks, the WCAG criterion, and the exact fix, with the code side by side." |
| 6 | Terminal: a11y-gate output ending "0 WCAG 2.2 A/AA violations"; then the failed PR check from the gate-bite proof | "And it stays fixed: our CI gate runs axe on every page and viewport and fails the build on a single A or double-A violation. Here it is catching one we planted on purpose." |
| 7 | Audit page stat cards (84 findings before, 0 after, 84 fixed), then VPAT page scroll | "The audit ledger is committed with the code: eighty-four findings before, zero after, and a draft conformance report covering all fifty-five WCAG 2.2 criteria." |
| 8 | Home page, dark theme, footer disclaimer visible | "Built by Lotus Innovations. If your product needs to meet WCAG 2.2 or Section 508, this is the working method. The link is below." |

Production notes: 1280x800 browser captures, cursor visible, no zooming
mid-clip; reduced-motion OFF for capture so the hero draw shows once;
disclaimer visibly on screen in the closing shot.
